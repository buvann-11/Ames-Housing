# House Price Prediction using Ames Housing Dataset

## Project Overview

This project is based on Chapter 2 of *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow*.

The objective is to perform Exploratory Data Analysis (EDA), preprocess the dataset, build machine learning models, and evaluate their performance on the Ames Housing dataset.

## Dataset

- Dataset: Ames Housing
- Target Variable: SalePrice

## Tasks Performed

- Loaded the dataset
- Explored the data
- Checked missing values
- Performed Exploratory Data Analysis (EDA)
- Built preprocessing pipelines
- Trained machine learning models
- Evaluated models using RMSE

## Libraries Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Results

Successfully completed the end-to-end machine learning workflow for house price prediction using the Ames Housing dataset.
